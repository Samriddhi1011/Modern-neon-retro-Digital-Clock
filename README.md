# 🌌 ChronoWave // Retro Neon Digital Clock

A neon-soaked, synthwave-inspired real-time digital clock built purely using vanilla **HTML5**, **CSS3**, and **JavaScript**. Designed with retro 1980s aesthetics, glowing cyberpunk neon aesthetics, moving grid animations, and interactive arcade themes.

## ✨ Features

- **Real-Time Precision:** Updates every millisecond with smooth seconds progress indicator.
- **Synthwave Vibe:** Animated 3D perspective neon floor grid and retro horizon sun.
- **Switchable Neon Themes:** 
  - ⚡ **Cyber** (Cyan & Hot Pink)
  - 🟢 **Matrix** (Acid Green & Deep Emerald)
  - 🌇 **Sunset** (Amber & Neon Magenta)
- **Interactive Controls:**
  - Toggle between **12H & 24H** time formats.
  - Switch **CRT Scanline Effect** ON/OFF for that authentic vintage monitor feel.
- **Zero Dependencies:** Built entirely with native web technologies—no frameworks, npm packages, or heavy libraries required.
